# Contributing

Thank you for helping improve Ball Game Classroom.

## Principles

Contributions should support at least one of these goals:

1. Make classroom use simpler for teachers.
2. Improve accessibility or multilingual support.
3. Protect learner privacy.
4. Improve reliability, testing or maintainability.
5. Add teaching value without unnecessary complexity.

## Development

Fork the repository, create a focused branch, make your change, and run:

```bash
npm run verify
```

The app has no build step. You can serve it locally with any static web server.

## Pull requests

Please keep pull requests focused. Describe:

- what problem you are solving;
- what changed;
- how you tested it;
- any accessibility, privacy or classroom-use implications.

For visible interface changes, screenshots are helpful.

## Translation contributions

Translations should use natural classroom language rather than literal machine translation. If possible, ask a fluent speaker or teacher to review the wording.

## Student privacy

Do not add collection of student names, identifiers, analytics, advertising identifiers or other personal data without a clear educational need and an explicit privacy design discussion.
