# Roadmap

Ball Game Classroom is developed as a practical teaching tool. Milestones are based on classroom usefulness, accessibility, privacy and maintainability.

## v1.0 — Classroom-ready foundation
- [x] Team-based question flow
- [x] Random ball/team selection
- [x] Timer and scoring controls
- [x] English, Bahasa Melayu and Tamil UI
- [x] JSON import/export
- [x] CSV result export
- [x] Offline service worker
- [x] Unit tests and CI

## v1.1 — Better teacher workflow
- [ ] Save multiple named question banks
- [ ] Duplicate/edit bank workflow
- [ ] Session resume prompt after accidental refresh
- [ ] Printable end-of-session summary
- [ ] Optional sound cues with mute control

## v1.2 — Accessibility and inclusion
- [ ] Conduct keyboard-only test pass
- [ ] Add high-contrast theme
- [ ] Add dyslexia-friendly text option without enforcing a special font
- [ ] Community translation architecture
- [ ] ARIA live-region review with screen readers

## v1.3 — Classroom insights
- [ ] Per-question response summary
- [ ] Topic-level accuracy summary
- [ ] Local-only formative assessment dashboard
- [ ] Export anonymised JSON report

## Future experiments
- [ ] Optional AI-assisted question drafting with teacher approval before use
- [ ] Optional curriculum-tag metadata
- [ ] Collaborative community question-bank format

AI-related features must remain optional, transparent and teacher-controlled. Student data should not be required for core gameplay.
